Regex Username Validation
A lightweight, modern UI component that validates usernames in real-time, live RegEx feedback, and zero dependencies.
✨ Features

    Real-time validation as you type
    3–16 characters, letters, numbers, underscore & hyphen only
    Responsive – works on mobile & desktop
    Vanilla JS & CSS – no external libraries

📦 Quick Start

    Clone / download the folder.
    Open index.html in any browser.
    Type in the input to see instant feedback.
